🎬 Movie Booking iOS App – Built with Storyboard in Xcode
The Movie Booking App is a sleek and user-friendly iOS application designed for booking movie tickets with ease. Developed using Swift and UIKit, and built entirely with Storyboard in Xcode, the app provides an intuitive visual interface and smooth navigation.

🔧 Key Features:
Home Screen: Displays a list of currently running movies with posters and brief info.

Movie Details View: Shows detailed information about selected movies including synopsis, cast, and duration.

Session Selection: Users can select preferred day and time slots from available showtimes.

Seat Reservation: Allows users to pick seats from a dynamic seat layout.

Login/Signup Flow: Simple user authentication system to manage bookings.

Booking Confirmation: Displays a summary of the selected movie, time, and reserved seats.

🛠️ Technologies Used:
Swift as the programming language.

UIKit for UI components and interaction.

Storyboard for designing the entire user interface visually.

Navigation Controllers and Segues for managing screen transitions.

This project is ideal for learning iOS development fundamentals, especially Storyboard-based UI design, view controller communication, and implementing navigation flows.
